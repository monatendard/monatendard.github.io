# Monatendard landing page

[monatendard.github.io](https://monatendard.github.io/)에서 제공하는 Monatendard 공식 랜딩 페이지입니다.

- 실제 `v0.3.0` WOFF2를 사용하는 견본과 타입 테스터
- 영문 1칸·한글 2칸 정렬, 합자, Nerd 아이콘 설명
- Windows·macOS(Homebrew)·웹폰트 설치 안내와 편집기 설정
- 정적 HTML, CSS, JavaScript만 사용하는 GitHub Pages 사이트
- 제목·본문은 Pretendard(jsDelivr CDN), 코드·견본은 Monatendard

릴리스 반영 절차는 [RELEASING.md](RELEASING.md)를 보세요.
