영문은 한 칸, 한글은 두 칸.

Monatendard는 Monaspace Neon의 영문을 원본 그대로 두고, Pretendard 한글을 원래 비율대로 영문 두 칸 폭에 맞춘 코딩 글꼴입니다.

설계

고정폭 글꼴에서 한글이 어긋나지 않도록 세 가지를 정했습니다.

한글 한 글자 = 영문 두 칸

영문 셀은 0.620em, 한글은 그 두 배인 1.240em입니다. 커서, 선택 영역, 들여쓰기, 표가 한글이 섞여도 같은 열에 맞습니다.

AA가
124012402480

영문과 기호는 Monaspace 그대로

영문 윤곽과 힌팅, 합자(rlig)와 문맥 대체(calt)를 손대지 않았습니다. 편집기에서 합자를 끄면 기호가 한 글자씩 보입니다.

켬!= === => -> <= >= :: ...
끔!= === => -> <= >= :: ...

Nerd 아이콘도 한 칸

Nerd판(Monatendard Nerd Font Mono)은 아이콘 10,352개를 영문 한 칸 폭으로 더합니다. 아래 Powerline 기호는 일반판에도 들어 있습니다. 누르면 복사됩니다.

편집기 설정

settings.json
"editor.fontFamily": "Monatendard, monospace",
"editor.fontLigatures": true

명령 팔레트에서 Preferences: Open User Settings (JSON)을 열고 추가합니다. 글자 크기와 줄 간격은 쓰던 값을 그대로 두면 됩니다.

Settings → Editor → Font에서 Font를 Monatendard로 고르고 Enable ligatures를 켭니다. IntelliJ IDEA, WebStorm 등 모든 JetBrains IDE가 같습니다.

settings.json · profiles.defaults
"font": {
    "face": "Monatendard Nerd Font Mono"
}

프롬프트에 Nerd 아이콘을 쓰지 않으면 Monatendard를 써도 됩니다. 크기를 바꾸려면 "size"를 더하세요. 단위는 pt이고 기본값은 12입니다.

init.lua
vim.opt.guifont = "Monatendard Nerd Font Mono:h12"

Neovide 같은 GUI 클라이언트용 설정입니다. h12는 글자 크기(pt)입니다. 터미널에서 쓰는 Neovim은 터미널의 글꼴 설정을 따릅니다.
