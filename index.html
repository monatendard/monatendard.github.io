Quick setup guide

에디터별 설정을
바로 복사하세요.

에디터 및 터미널 환경에 맞는 설정을 복사해 바로 사용할 수 있습니다.

settings.json 
{
  "editor.fontFamily": "Monatendard, Consolas, monospace",
  "editor.fontLigatures": true,
  "editor.fontSize": 14,
  "editor.lineHeight": 1.6
}

💡 VS Code 설정 파일(Ctrl + Shift + P → Preferences: Open User Settings (JSON))에 위 구문을 추가하세요.

Font Settings (Preferences/Settings → Editor → Font) 
Font: Monatendard
Enable ligatures: Checked

💡 IntelliJ / WebStorm 설정 창에서 Font 항목에 Monatendard를 지정하고 Enable ligatures를 체크하세요.

settings.json (profiles.defaults) 
"font": {
    "face": "Monatendard Nerd Font Mono",
    "size": 11
}

💡 Powerline 및 Nerd Font 아이콘을 사용하는 터미널에는 Monatendard Nerd Font Mono 패밀리를 권장합니다.

init.lua (GUI Neovim) 
vim.opt.guifont = "Monatendard_Nerd_Font_Mono:h12"

💡 Neovide 또는 VimR 같은 GUI Neovim 환경에서 위 구문을 추가하세요.
